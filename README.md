# Pre-Med Science Masterclass

An offline pre-medical science textbook: chemistry, biochemistry, physics, biology, cell biology,
genetics, anatomy & physiology and pharmacology — 167 chapters with real 3-D models and simulations.

**On an iPad or iPhone:** open the site in Safari, tap the share button, then **Add to Home Screen**.
Tap **Save** when it offers to store the 3-D models, and the whole book then works with no internet.

Built from source with `python build.py && python _qa/make_pages.py`.
